# Steve’s Apple — лендинг магазина техники Apple

Концепт-редизайн сайта магазина техники Apple в Батайске. Вместо типового сайта-конструктора — тёмный «журнальный» лендинг, построенный вокруг фотографий магазина.

**Демо:** https://vadex-web.github.io/steves-apple/

## Что внутри

- Прелоадер с монограммой и счётчиком лет «since 2014»
- Первый экран с медленным приближением фото и появлением заголовка по словам
- Закреплённый блок iPhone 16: фото меняются, пока листаешь функции (IntersectionObserver)
- Список «что мы делаем при покупке» с анимированными галочками
- Каталог с фотографией, которая плавно следует за курсором
- Горизонтальная лента постов с перетаскиванием мышью
- Живой статус «Открыто / Закрыто» и подсветка сегодняшнего дня по московскому времени (`Intl.DateTimeFormat`)
- Адаптивная вёрстка, поддержка `prefers-reduced-motion`

## Стек

HTML, CSS, Vanilla JavaScript — один файл, без сборки и зависимостей. Хостинг — GitHub Pages.

## Запуск

Открыть `index.html` в браузере или включить GitHub Pages для ветки `main`.
